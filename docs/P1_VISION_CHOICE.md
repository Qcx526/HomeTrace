# P1 视觉方案：参考实例特征匹配

**选择：OpenCV ORB + Hamming 匹配 + RANSAC 单应性检验。** 本阶段要证明“读取图片、验证已登记物品外观、失败后继续搜索”的完整链路；不训练新模型，也不做通用物体类别识别。OpenCV 官方教程给出 [ORB 二进制特征与 Hamming 匹配](https://docs.opencv.org/4.12.0/dc/dc3/tutorial_py_matcher.html) 和 [特征匹配结合单应性定位已知平面对象](https://docs.opencv.org/4.12.0/d1/de0/tutorial_py_feature_homography.html) 的成熟流程。

| 方案 | 本阶段取舍 |
| --- | --- |
| ORB + Hamming + RANSAC | 选用。无需权重或训练，参考图可由用户自行拍摄，CPU 离线运行；适合有纹理的近似平面外观。 |
| SIFT + RANSAC | 同类候选，暂不引入第二套策略。若真实素材上的 ORB 效果不足，再以相同图片实测比较。 |
| 小型目标检测模型 | 通常先确认类别，不能直接证明是用户登记的特定物品；还需权重许可、下载与实例验证。当前不引入。 |
| 大型 VLM / 云视觉 API | 本阶段不需要，增加依赖和演示环境约束。 |

## 验证与结果语义

实际读取参考和场景图像，提取 ORB 特征，经过近邻比值筛选、互异匹配、RANSAC 内点与几何有效性检查后，才允许 `FOUND`。证据记录方法、图像哈希、匹配点、内点、覆盖度和实际处理时间。不足以确认的匹配返回 `SUSPECTED` 或 `UNKNOWN`；缺失、损坏、遮挡和低纹理输入不产生可靠负证据。判断不能读取清单中的人工答案。

`reference_instance_match` 的含义是“当前图片的平面纹理与登记参考外观一致”。它不是类别识别，也不能区分两件使用完全相同印刷包装的实体。近似平面假设、纹理、遮挡、光照、清晰度和目标像素尺寸都会影响结果；不能由公开样例成功推断所有遥控器或家庭物品都可识别。

## 开源与复现

使用 OpenCV 4.x 的现成实现，不包含模型权重。OpenCV 4.5 及以后采用 [Apache-2.0](https://opencv.org/license/)；Python wheel 及其第三方组件的具体版本/许可以安装后的包元数据为准。测试照片固定来自 OpenCV 4.12.0 的指定提交，原文件、SHA256、URL 和版权告知见 [样例来源说明](../examples/recorded_images/README.md) 与 [sources.json](../examples/recorded_images/sources.json)。参考图与场景图均为公开实拍，地点和时间则是明确标识的 Demo 编排。

实测必须记录运行环境、正例/负例数量、误报/漏报和 PC 实际耗时，并与自动化测试日志一起提交。公开样例仅构成小样本冒烟验证，不是精度基准；未取得团队拍摄素材或端侧设备时，家庭场景效果与端侧延迟均标为未验证。具体运行结果以本 PR 的原始测试与 Demo 证据为准，不使用模拟导航时间或估计值冒充设备性能。

## 本次 PC 实测

Windows 10 / Python 3.11.4 / OpenCV wheel 4.14.0.94 / NumPy 2.4.6；CPU 标识 Intel64 Family 6 Model 151，12 个逻辑核心，OpenCV 固定使用 1 线程、随机种子 0。四张不同的场景照片分别执行 10 次计时；重复执行不增加独立样本数，注册参考图的自匹配不计入正例。耗时包括文件读取/哈希、解码、特征和几何检查，不含解释器启动及参考图特征初始化，可能利用文件缓存。

| 场景照片 | 实际结果 | 好匹配 / 内点 | 中位耗时 ms |
| --- | --- | --- | --- |
| `box_in_scene.png`（正例） | FOUND | 45 / 41 | 32.6045 |
| `apple.jpg`（负例） | SUSPECTED | 9 / 0 | 10.2255 |
| `orange.jpg`（负例） | UNKNOWN | 3 / 0 | 11.7300 |
| `fruits.jpg`（负例） | SUSPECTED | 4 / 0 | 30.5595 |

这 1 个正例、3 个负例中没有误报 FOUND，正例成功确认，但两个负例存在少量错误候选，最终为 SUSPECTED。这不是零误识别或通用准确率证明；界面与讲解必须把疑似与已确认分开。完整逐图诊断、最小/中位/最大耗时与运行环境见 [实测 JSON](evidence/issue-2/vision-results.json)。端侧设备延迟、团队家庭场景和真实机器人仍未验证。
