# 初赛 Demo 验收 v0.1

## 截止时间
2026-10-28 12:00（以组委会最新公告为准）。

## 必备场景
A. 物品记忆：至少一张真实拍摄图片关联到注册物体、位置与历史时间。
B. 位置变化：用户将物品从地点 A 移动至 B；系统先检查 A，再重新规划并找到 B。地点与图片结果不是直接泄露给规划器的真值。
C. 负例：物体不存在、图片遮挡或不可观察时报告 UNKNOWN / NOT_FOUND_IN_VIEW，而非 FOUND。

## 验收门槛
- 新环境按 README 步骤安装运行，有单命令启动 Demo/CLI。
- 三个场景均提供可重复执行步骤、机器可读日志和人工核验图像。
- 在无真实机器人环境下，明确提示 Mock navigation；不宣称真机完成。
- 每个找到的结果可追溯到具体观测图像；历史位置不得被冒充为新发现。
- pytest 覆盖状态机、规划、记忆更新及至少一例负向路径。
- 同一测试场景上比较固定搜索顺序与记忆优先搜索的步骤数/耗时（若使用模拟时间需明确标记）。
- 技术报告描述哪些开源算法被复用，哪些是项目特定改造；所有实验数据保留来源。

## 交付包
赛事指定 Word；PPT；真实软件演示视频；源码；运行说明；测试与结果表。可选网页 UI。不以不完整功能图片代替可运行代码。

## 进度/审查
Codex 在 PR 中提交：改动摘要、启动命令、测试结果、样例日志、已知局限和下阶段风险。没有测试证据不进入已完成。
