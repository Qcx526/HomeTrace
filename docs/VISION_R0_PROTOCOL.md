# Vision R0：复用实拍的诊断与方案筛选协议

2026-10-26，依据项目负责人当日 Vision R0 合同及“暂无新照片，先完成诊断与对照”的补充。关联 Issue #4，独立分支 `feature/4-vision-r0`，main 基线 `4429fcf21797d6af05d189effdd510918315acc4`。优先于材料制作，不启动 DataForge，不改生产 Agent/SearchCore/检测阈值，不覆盖历史报告。PR #15 仍单独等待 PM 复核。

## 数据边界

旧 P3 的 75 次是 25 图对乘 3 方法；R1 是新包 24 张、4 参考和 20 场景、两种模式共 40 计划项；YOLOE 是同样 20 场景。新旧包存在图像字节重复，不能把实验次数当图片数。输入和哈希在运行前后核验。

已有图片全部标为 `diagnostic_reused`，参考标 `registration_only`；无 `independent_test`。不得把已有图片重新随机切分后宣称独立验证。保留原人工 presence 标签（6 正、8 负、5 不确定、1 辅助），不按检测结果改标签。现有标签没有完整目标框/遮挡比例/认证采集批次；未知项保持 null 或 unverified，不能用模型预测填成真值。

正式定位指标需要负责人确认的实例真值框；人工/开发者视觉诊断只作单独质性记录。图像出现标签的 TP/FP 仅是 image-presence proxy，不代表框落在正确实例。相似熊猫必须区分大玩偶与登记小挂件。

## 固定对照（先记录本协议，再执行新增方案）

1. 复跑旧 P3 ORB/SIFT/AKAZE 75 项、R1 全图/固定 ROI 40 项、固定 YOLOE 20 场景。首次使用 Agent 环境时发现 OpenCV 4.12.0 与历史 4.14.0 不同，保留该轮，另用原 4.14.0 环境复跑传统基线，不混称同版本精确复现。
2. 在同一新包 20 场景上比较 ORB 全图/固定登记 ROI；SIFT 全图/固定登记 ROI；AKAZE 全图/固定登记 ROI。没有为搜索图提供人工目标框。
3. 比较固定 YOLOE 候选定位 + 固定登记 ROI 的 SIFT 几何核验。只使用本轮实际 YOLOE 预测框产生候选裁剪；所有候选都处理，不按标签选框。不下载新模型、不改 YOLOE 参数。输出映射回原图坐标；无候选不跳过整张评价。
4. 上述 SIFT/AKAZE 复用现有实验实现的 ratio、最少匹配/内点、内点率、覆盖与几何门槛，不调阈值、不训练。SIFT 的 L2 与 ORB/AKAZE 的 Hamming 距离单位不同，继续使用原有距离定义。
5. 实验 `FOUND` 只表示既有几何规则接受，不写入 SearchCore/SQLite/Agent，不冒充物理实例身份已验证；候选定位本身永不产生 FOUND。对照后不自动选胜者进入生产。

每项记录输入哈希、方法/配置/源码版本、参考关键点、场景关键点、匹配数、内点/覆盖、状态/原因、原图坐标框、运行时间及设备。私有数据仅在 ignored 目录，公开输出限匿名统计。时间范围分别说明，不能混用含/不含登记或模型加载的时间宣称加速。

诊断还检查 EXIF 方向、解码尺寸、登记 ROI 的物体/背景支持、质量门槛、目标尺度/视角/遮挡与直接失败点。视觉外观解释属于假设时明确注明，不用单个失败推断因果。

## 演示验收门槛（本轮预先提出，待 PM 确认）

本轮筛选门槛：相同复用数据中至少出现可核查的正确目标几何候选，8 个明确负例无错误接受，同时提供所有失败和相似实例案例。此门槛只能支持后续研究，不能证明泛化提升。

独立小 Demo 门槛：先选定一个物理实例、冻结登记图/ROI/算法/参数，再取得至少两次独立采集批次的 6 张目标出现、8 张目标缺失/相似物体照片。6 正例至少 5 个正确实例且框 IoU≥0.5；8 负例零错误接受；接受结果的实例 precision≥0.95（零接受时 precision 未定义、不能通过）。全套都参与评分，包括登记/解码失败。即使通过也只代表这一受限 Demo，不是家庭通用可靠性保证。

建议正例覆盖不同背景、远近、约 ±30° 视角、一个部分遮挡和两种室内光照；负例包括空登记背景、其他背景、相似但不同实例、只有大熊猫等。同批近重复图必须放在同一分区。调参/补拍登记与最终测试分批；测试结果不可用于继续调参后复称独立。真实物理身份、采集批次和真值框由负责人核对。未取得独立数据时 precision/recall/FPR 均报告 null / BLOCKED。

## 决策边界

YOLOE 继续 NO_GO。无法确认返回 UNKNOWN/SUSPECTED，不降低门槛。生产修改只能在诊断及对照后有证据支持且经 PM 评审；没有独立证据时结论必须是“真实家庭识别改善尚未证明 / BLOCKED”。

技术依据：OpenCV [特征匹配与单应性](https://docs.opencv.org/4.13.0/d1/de0/tutorial_py_feature_homography.html)、[SIFT 尺度空间](https://docs.opencv.org/4.13.0/da/df5/tutorial_py_sift_intro.html)支持这一有限局部特征对照；[YOLOE 官方说明](https://docs.ultralytics.com/models/yoloe/)描述视觉提示候选，不能据此推断特定物理实例身份。实验继续固定本地 8.3.221 API 和权重，不跟随官网新版模型切换。
