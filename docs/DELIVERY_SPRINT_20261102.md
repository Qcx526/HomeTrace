## 已知事实与本轮边界

- 现有 SearchCore、SQLite、Agent 工具轨迹、历史与当前观察分离、旧图重放保护可继续复用。导航仍为模拟，记录照片不等于实时机器人采图。
- 当前网页 Agent 按运行创建样例数据库，没有完成可长期使用的家庭工作区；现有工具没有对话登记接口，跨轮确认与恢复也尚待开发。
- 最新 R2 受控实验仍为 NO_GO，家庭实例识别为 **BLOCKED**。此前 499 项测试通过是对应代码的回归事实，不是本轮测试结果，也不是家庭识别通过。见 [冻结实验结论](VISION_R2_CONFIDENCE_WARMUP_20261026.md)。
- 当前 18 张水杯照片全部已参与开发探索，没有未使用过的独立实拍测试集。不得重新拆分后称为独立测试。
- 本轮验证“共享冻结模型 + 物体参考库”：登记新增物品主要执行区域确认、特征提取和档案存储，不为每个物品训练一个网络。候选框、类别分数、检索相似度均不能直接升级为生产 FOUND。
- 目标 Demo 范围为三个地点、最多三类物品的连续记忆与寻找；这是收敛目标，**并非已支持三类识别**。具体物品须依据实测选定。钥匙、水杯、手表、眼镜、手机是需求候选，尚无“大部分日常物品均可识别”的证据。

## 最小可交付行为

1. 登记：主人确认“哪件物品”，页面明确“这里”的位置来源，保存参考档案与证据后才回复保存成功。主人告知的位置与视觉确认位置分开记录。
2. 记忆：持久家庭工作区保留实例 ID、别名、参考图、带时间与来源的位置事件；重启与新会话不得清空。参考外观更新需可靠确认，防止误识别污染参考库。
3. 寻找：优先检查最近可靠位置；根据真实历史和本轮工具反馈选择下一地点；画面没有检测到不能证明整个房间不存在目标。
4. 结果：区分已确认、待确认与 UNKNOWN；相似物品、空背景、不可辨识同款实例和遮挡必须能够拒识。人工协助登记或确认须显式标明，不计作自动识别成功。
5. 页面：显示当前物品、历史、当前观察、实际工具轨迹与证据；预录回放和模拟导航始终有标识。未来实现的会话登记与多轮恢复不能写成本 PR 已完成功能。

## 数据和训练约束

| 来源 | 本地必须记录 | 可以支持的结论 |
| --- | --- | --- |
| `real` 真实拍摄 | 文件 SHA256、已知拍摄来源、人工确认标签、使用历史；未知元数据保持未知 | 对该真实样本的结果；独立验收还需冻结后未参与选择或调参的新场景 |
| `augmented` 实拍或合成原图的增强 | 父图哈希、父图来源、变换参数、生成工具版本、所属训练组 | 指定增强条件下的开发或训练结果，不增加独立实拍样本数量 |
| `synthetic` AI 生成 | 生成模型/版本、提示词、生成时间、输出哈希、人工复核与许可证信息 | 合成场景表现或补充训练证据，不能证明生成物是主人现实中的特定物理实例 |

- 原图、近重复图及其增强后代放在同一数据组；只在 train 内增强，评估标签不得进入检测或参考选择。
- 合成图的类别外观不能替代实际登记参考，模型预测框不能直接作为人工真值。真实、增强、合成结果分开统计。
- 当前先运行冻结模型和已有真实数据对照；**没有明确训练缺口时不批量生成图片，也不启动大规模 DataForge**。不以生成数量占用 Demo 与材料时间。
- 仅在对照确认必要时，按单一失败类型做小批合成训练试验，事先固定实验数、预算、参数与停止条件。每次训练仍需真实正负例复核；不绕过旧 R2 实验额度，不覆盖旧模型或报告。
- 私人照片、标签、身份信息、权重、数据库和 API Key 继续留在 ignored 本地目录。公共 PR 只提交代码、合同与脱敏证据。

## 验收与停止条件

- 已有开发图片可筛选方案，不能证明泛化改善。冻结后独立受限验收仍需至少两批新场景、6 张正例和 8 张负例：至少 5/6 正例 IoU≥0.5、8/8 负例零误接受、实例 precision≥0.95；零接受时 precision 未定义，不能通过。未执行、拒识和失败全部计入报告。
- 不要求负责人提供大量训练图。若后续无法提供少量独立验收照片，继续完成当前数据支持的工程和材料，但“独立真实家庭识别已通过”保持 BLOCKED。
