# Vision R3：共享冻结模型与登记式记忆实验协议

Issue #22，依据负责人 2026-10-27 最新授权。分支基于 PR #21，尚未合并。不是 R0/R1/R2 历史结果的修订，也不解除 YOLOE NO_GO。

## 预先固定的最小实验

- 共享检测器：已有官方 YOLO11n，完整场景推理，imgsz=640/960，conf=.25，NMS IoU=.7，max_det=100；只把 cup 类作为本次水杯候选。这不代表已经支持钥匙等类别。
- 共享编码器：Meta 官方 DINOv2 ViT-S/14，384维 CLS 特征，模型参数全部冻结，零训练步骤。源提交 `7764ea0f912e53c92e82eb78a2a1631e92725fc8`，权重 SHA256 `b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9`。模型代码及权重不进公开提交。
- 编码预处理：物体 ROI 整体 RGB 裁剪，双三次缩放到224×224（会改变长宽比），ImageNet均值/标准差，不做随机增强。
- 参考库：沿用负责人已确认身份和 ROI 的 1.jpg、6.jpg（SONY）与10.jpg（卡通 rival）。不重新画框、不读取场景答案选参考。采集时间、批次仍未知，不套用或伪造 R1 独立采集资格。
- 场景：全部18张原图执行两个分辨率；以上3张参考图执行但按原图hash拒绝重放，不计搜索成绩。剩余15张为10正5负开发样本；无独立测试。这个计数来自已有审核标签，仅供事后评分。
- 推理进程只读参考ROI及无标签场景清单。单独评分进程才读历史人工审核框。原图与旧实验输出不可覆盖。
- 固定实验规则：至少两条不同原图hash的目标参考相似度≥.70，目标前两条平均相似度比最佳rival分数高≥.05。只有一条rival参考，必须报告控制有限。阈值是**未经校准的预设诊断门槛**，不因本轮结果修改；仅输出 `APPEARANCE_SUPPORTED/UNKNOWN`，绝不输出生产FOUND/确认物理身份。
- 输出全部候选、逐参考相似度、框、耗时、GPU内存、原图与模型hash、拒识原因。比较同一批全图检测框在检索前后的TP/FP/FN，并单列参考排除、未执行和失败项。

## 数据与后续边界

当前参考登记增加数据记录，不训练新网络；位置记忆只写独立数据库的主人陈述，不伪造视觉观察。

本轮零合成图、零增强图、零训练，不需要负责人补大量训练照片。用户允许的AI图仅在明确需要训练时作为单独标识的补充来源；不能代替主人实体的真实参考，也不能用来宣称真实家庭验收通过。后续若改变模型、预处理、参考或门槛，必须建立新实验版本，不覆盖本轮。

通过开发诊断后仍需要冻结规则后的真实独立验证：至少6正8负、两批场景，5/6正确定位IoU≥.5、8/8负例无错误接受、实例precision≥.95（零接受不通过）。缺少该证据时生产识别继续BLOCKED，不将开发分数写成泛化能力。
